# AGENTS.md

## Project context
- This repository manages an R package for plotting matrix data as heatmaps.
- The core data structure is derived from the Bioconductor SummarizedExperiment class.
- Plotting is based on the ggplot2 api.  Plot elements are composed with patchwork.
- The package is intended for submission to Bioconductor.

## Working practices
- Explain the existing code behavior before changing it.
- For R changes, run the relevant checks and report what you ran.
- Summarize changed files.
- Use a coding style similar to the documents you find in the R directory where possible.  If necessary, this should be superceded by Bioconductor coding style.
